# benchmarks/

Earth geophysics datasets for inversion algorithm validation before Titan-specific physics.

## dl_rmd_sample/

Subset of [DL-RMD (Zenodo)](https://doi.org/10.5281/zenodo.7260886) — resistivity models + EM responses.

**Use:** Sanity-check `local_invert` and `centralized_invert` against known 1-D EM inversion behavior.

**Code reference:** [github.com/rizwanasif/DL-RMD](https://github.com/rizwanasif/DL-RMD)
