# materials/

Physics parameter bounds for synthetic environment generation.

**Expected file:** `titan_materials.csv`

| Column (planned) | Description |
|------------------|-------------|
| `material_class` | e.g. water_ice, hydrocarbon_liquid, tholin |
| `dielectric_min`, `dielectric_max` | From [UCSC Titan Materials DB](https://titanmaterials.sites.ucsc.edu/) |
| `density_kg_m3` | Phase-appropriate density |
| `source` | Citation / URL |

**Source:** Export or transcribe from UCSC database + ApJS 2023 paper.
